**推荐路径** (4-6 小时):
```
1. 完成主线 11 步 (绿谷 → 铁锈 → 硅火 → 苍穹)

2. 选择 1-2 个喜欢的支线探索
```

**推荐路径** (20-25 小时):

## 📥 安装与更新

### 从 v1.3.0 升级到 v2.0.0

1. **备份存档** (重要！)
   ```
   备份 saves/ 目录
   备份 config/ 目录
   ```

2. **更新整合包**
   ```
   下载 v2.0.0 并替换文件
   保留 saves/ 和 config/ 目录不变
   ```

3. **首次启动**
   ```
   游戏会自动加载新任务
   旧版本进度会自动迁移
   新任务会逐步解锁
   ```

4. **验证安装**
   ```
   打开任务书，检查是否有 280 个任务
   检查主线 11 步是否显示
   检查 4 个星球是否正确显示
   ```

### 注意事项

⚠️ **不要删除旧版本的任务文件** - 需要兼容迁移  
⚠️ **不要在游戏中途更新** - 请重启客户端  
⚠️ **如遇到问题，恢复备份** - 然后提交 Bug 报告
