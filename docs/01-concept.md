# 01 · 概念设计（Phase 1）

## 整合包名称

- **中文**：星际文明编年史
- **英文**：**Starfall Chronicles** — *A Chronicle of Stellar Civilizations*
- **标识/前缀**：`starciv`（全部自定义物品、维度、进度沿用此命名空间）

## 核心钩子（一句话）

> **你在一片麦田里醒来，头顶是四颗星球。一万年前，上一个文明把种子留在了这里——现在，轮到你沿着星门，把文明重新点亮。**

## 文明阶梯总览

| 星球 | 维度 | 文明等级 | 核心玩法一句话 | 标志性模组 | 代价 |
|------|------|---------|---------------|-----------|------|
| 绿谷星 | `minecraft:overworld`（主世界即绿谷） | 农耕文明 | 深度农业、四季、酿造、村落、与自然共生 | Farmer's Delight、Serene Seasons、MineColonies | 无（治愈与创造的起点） |
| 铁锈星 | `starciv:rustfall`（数据包自定义） | 工业文明 | 采矿、机械、流水线、污染治理 | Create、Immersive Engineering、Pollution of the Realms | 污染反噬玩家 |
| 硅火星 | `starciv:silicon`（数据包自定义） | 信息文明 | 自动化、编程、量子计算、赛博都市 | AE2、CC:Tweaked、Integrated Dynamics | 人性被算法替代 |
| 苍穹星 | `starciv:stellaris`（数据包自定义） | 星际文明 | 火箭、反物质、基因工程、外星遭遇 | Ad Astra、L_Ender's Cataclysm、Mekanism | 个体意识被稀释 |

每个星球**不是换皮**：玩法逻辑完全不同（见下文）。

## 一、绿谷星 · Verdant Vale（农耕文明）

### 核心模组（模组名 + 版本快照 + 作用）

| 模组 | 版本（Modrinth 快照） | 叙事作用 |
|------|----------------------|---------|
| Farmer's Delight | 1.20.1-1.3.3 | 深度烹饪、丰收节、厨刀/灶台——农耕日常 |
| Brewin' and Chewin' | 1.20.1-3.2.1 | 果酒/奶酪发酵——酿造文化 |
| Serene Seasons | 9.1.0.3 | 四季系统：雨水与季节决定收成 |
| Productive Bees | 1.20.1-12.6.0 | 养蜂产业链：花粉→蜜→基因样本 |
| Naturalist | 5.0pre4+forge | 真实动物行为与生态观察 |
| Alex's Mobs | 1.22.9 | 野生动物与事件 Boss（自然威胁） |
| Botany Pots | 13.0.43 | 花盆种植=温室墙（自动化雏形） |
| MineColonies（CurseForge） | 1.20.1 | 殖民地建设=村落文明本身 |
| Quark / Supplementaries / Decorative Blocks | 4.0-462 / 3.1.43 / 4.1.3 | 建筑与生活装饰，统一视觉语言 |
| Easy Villagers | 1.1.39 | NPC 交易与村落经济 |

### 玩法循环（每天做什么）
早晨看天气与季节 → 播种/收成/酿造 → 喂蜂、放牧、扩建村落 → 与村民交易 → 傍晚烤面包、酿果酒、处理 Anthropoi 事件（Alex's Mobs）→ 睡觉/继续夜作。

### 视觉风格
金色麦浪、翠绿丘陵、四季分明（Serene Seasons 的落叶与积雪）、朴素石木建筑；Terralith 提供地貌多样性；YUNG's 系列提供上古遗迹的叙事废墟。

### 独特机制
- **四季与天时**：春耕秋收，冬季作物减产——玩家必须规划储备。
- **村落即文明**：MineColonies 的殖民地等级=人均生产力。
- **上古之种**：独石碑（KubeJS 代码生成）是文明起点；上古之种是全包最重要原料。

### 向铁锈星过渡（任务链，非“造个火箭”）
1. 完成农耕里程碑（播种→收成→面包师→蜂农/商人）。
2. 探索独石碑遗迹（KubeJS 半径探测），获得**上古之种**。
3. 压榨精粹 → 锻造**星门钥匙**（金+绿宝石+石英+文明精粹）。
4. 在主世界星门（出生点东侧）右键星门核心 → 跃迁铁锈星。

## 二、铁锈星 · Rustfall（工业文明）

### 核心模组

| 模组 | 版本快照 | 叙事作用 |
|------|---------|---------|
| Create | mc1.20.1-6.0.8 | 机械传动/装配线——工业时代主玩法 |
| Create: Steam 'n' Rails | 1.7.3+forge | 蒸汽火车=跨矿区物流大动脉 |
| Create Addition | 1.3.x | 电气化：电阻/电机（蒸汽→电力跃迁） |
| Immersive Engineering | 10.2.0-183 | 多块高炉/电线重工业美学 |
| Mekanism | 10.4.16.80 | 通用机器/终极能源（跨星球通用） |
| Industrial Foregoing | 3.5.22 | 激光钻、自动屠宰——集约化流水线 |
| Pipez | 1.2.26 | 物品/流体/能量/气体物流标准化 |
| Pollution of the Realms | 8.1.49.0 | **污染机制**：排放反噬存亡 |
| PneumaticCraft | 6.0.23 | 气压/无人机——工业向信息过渡桥 |

### 玩法循环
探矿采煤 → 搭建能源（蒸汽/黄铜）→ 炉与机床炼钢 → 流水线与火车物流 → **观察污染值**：超标则酸雨、作物枯死、怪物增强，需治理（净化器/碳捕集）。

### 视觉风格
锈红与烟灰色调、橙色天空（自定义生物群系 `starciv:rust_wastes` 的 fog/sky 色）、锈水（water_color 调色）、巨型蒸汽机械剪影。

### 独特机制
- **污染即存亡**：Pollution of the Realms 让排放物累积；绿谷星带来的种子可作生物燃料 → 清洁能源循环。
- **物流即权力**：Pipez + Create 蒸汽火车运输重型物料。

### 向硅火星过渡
1. 炼钢 + 建立能源网络 + 铺设物流。
2. 用上古之种（从绿谷星带来）在 Create 混合机酿造**生物燃料罐**。
3. 锻造**精密零件**（create:iron_sheet + 红石 + mekanism:dust_gold）。
4. 携带生物燃料罐，在铁锈星星门跃迁（消耗 1 罐）→ 硅火星。

### 核心模组

| 模组 | 版本快照 | 叙事作用 |

| Applied Energistics 2 | 15.4.10 | 量子存储/自动化网络（复杂路线） |

### 玩法循环
搭建存储网络（AE2 或 RS 选一）→ 写 CC 程序自动化流水线 → 用 Integrated Dynamics 做逻辑控制 → 用数据碎晶（紫水晶研磨）当通用货币交易 → 偶尔面对“工厂爆炸”的代价。

### 视觉风格
深蓝紫霓虹夜色（`starciv:silicon_city` 群系：暗紫天空、青色雾、海晶灯霓虹点阵）、混凝土高密度都市感、Chipped 建材阵列。

### 独特机制
- **代码即力量**：CC: Tweaked 的 Lua 脚本控制整条生产线；逻辑错误 = 熔毁。
- **双路线分支**：AE2（强大但复杂）vs RS（简单但上限低）——玩家必须选择专精。
- **数据货币**：data_slivers 作为星球交易媒介。

### 向苍穹星过渡
1. 建立网络 + 写码 + 获取数据碎晶。
2. 用铁锈星带来的**精密零件**锻造**量子核心**（含 AE2 计算处理器）。
3. 在硅火星星门跃迁（需信息阶段）→ 苍穹星。

- **新游戏+**：文档提供多周目规则建议（保留科技+宇宙熵增威胁）。

## 跨文明经济系统（物流设计）

资源在不同星球流通 = **星门燃料经济**：

```
绿谷星产出：上古之种 / 精粹 / 食材
   ↓ 随身携带（玩家背包/精致背包）+ 星门消耗燃料规则
铁锈星：种子 → 生物燃料罐（星门燃料），精密零件
   ↓
硅火星：精密零件 → 量子核心，数据碎晶（货币）
   ↓
苍穹星：量子核心 → 跃迁核心/引擎
```

- 玩家是唯一物流节点：背包扩充（Sophisticated Backpacks）+ 每个星球可建传送石碑（Waystones）形成星球内物流，星门负责星际。
- 设计上**禁止**单星球自我闭环：量子核心必须消耗铁锈星的零件（配方 gated + 消耗），生物燃料必须消耗绿谷星的种子。
- **流通度量**：食物/种子/零件/碎晶四类物品跨越星球流动，任何一类断供都会卡住科技树——这就是“经济”。

## 主线任务大纲（10-15 关键节点）

1. 醒来：收下《文明编年史》（KubeJS 首次登录赠送）。
2. 播种 → 第一穗 → 面包师（农耕三连）。
3. 蜂农/商人分支（专精选择起点）。
4. 独石碑遗迹 → 上古之种（跨文明起点）。
5. 星门钥匙 → 首航铁锈星。
6. 炼钢/机械/管道三线并进。
7. 蒸汽动脉（铁路）。
8. 生物燃料（农耕×工业交汇）。
9. 精密零件 → 跃迁硅火星。
10. 建立网络/写码（分支：AE2 or RS）。
11. 数据碎晶经济。
12. 量子核心（工业×信息交汇）→ 跃迁苍穹星。
13. 航天工业（Ad Astra 钢板/火箭）。
14. 跃迁核心 → 跃迁引擎（信息×星际交汇）。
15. 失落科技揭示 + 灾厄 Boss 图鉴 + 终局灯塔。

## 终局追求

- **故事**：失落科技（最原始的才是最先进的）。
- **战力**：Cataclysm 全 Boss 图鉴。
- **产能**：恒星级能源（反物质），向社区提交“戴森球完成度”。
- **自由**：跃迁引擎任意返航 → 每个星球都是你的家。
