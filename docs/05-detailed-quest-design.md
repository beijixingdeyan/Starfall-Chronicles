# 【主线】Starfall Chronicles · 11 步主线（完整版 snbt 代码生成）

## 11 个主线任务的详细描述和坐标

### ① 【开局】史书与手册 → 出发
- **目标**：收集 《文明编年史》（完成任务开启后自动获得）
- **任务说明**：
  你在一片麦田里醒来，头顶是四颗不同的星球。这不是巧合——一万年前，上一个文明把种子留在了这里。现在，轮到你沿着星门，把文明重新点亮。
  
  第一本书《文明编年史》是指南针。打开任务书（K 键），跟着【主线】箭头，一步一步探索这个被遗忘的世界。
  
  学习阶段：本章会教你种植、制造、交易、能源的基础。其他按键帮助：
  - K = 任务书（树状图，跟我走）
  - Q = 图鉴百科（已解锁的物品和 Boss）
  - J = JEI 配方（查配方和合成）
  - E = 背包
- **坐标**：出生点附近（绿谷星，中枢）
- **奖励**：《文明编年史》×1、《探索手册》×1
- **下一步**：找到独石碑

### ② 【农耕】独石碑 → 获得上古之种
- **目标**：靠近独石碑，触发"文明回忆"
- **任务说明**：
  从出生点出发，朝东北方向走。你会看到一根闪烁着紫色光芒的巨大独石碑——这是上一个文明留下的标记。
  
  靠近它（距离 26 格内），它会向你倾诉：这是文明的种子。它记得每一个时代。
  
  你会自动获得 2 粒【上古之种】。这是一切的开始。
- **坐标**：大约 (26, ?, -126)，绿谷中心东北方向
- **奖励**：上古之种 ×2
- **下一步**：找耕地，种植上古之种

### ③ 【农耕】种植上古之种
- **目标**：在耕地上右键种植上古之种，等待成熟
- **任务说明**：
  找一块耕地（或自己创建：用锄头右键草地变成耕地）。
  
  **种植方法**：手持【上古之种】，右键耕地 → 会自动在耕地上方放置【上古作物】方块。
  
  **生长时间**：5-15 分钟（平时期望 10 分钟），雨天会加快。
  
  **收获**：方块变亮后（方块显示为完全成熟的金色绿叶），右键收获 → 掉落【上古之种】×1 + 【文明精粹】×1。
  
  文明精粹是农耕文明的精华，接下来要用它来制造星门钥匙。
- **坐标**：任意有耕地的地方（建议靠近出生点）
- **奖励**：文明精粹 ×1、经验 ×1 级
- **下一步**：合成星门钥匙

### ④ 【交易】合成星门钥匙
- **目标**：在合成台上制作【星门钥匙】
- **任务说明**：
  打开 JEI（J 键），搜索"星门钥匙"（Stellar Key）。
  
  配方需要 4 种材料：
  - 金锭 ×3（从金矿烧制或找村庄交易）
  - 绿宝石 ×1（开采或商人交易）
  - 石英 ×1（下界采集或合成）
  - 文明精粹 ×1（刚从上古作物获得）
  
  在工作台上合成这些，最后按配方排列在合成台上。成功！你现在手持着打开星门的钥匙。
- **坐标**：工作台（附近建造或找村庄）
- **奖励**：星门钥匙 ×1
- **下一步**：去星门，右键打开通路

### ⑤ 【交通】跃迁铁锈星
- **目标**：用星门钥匙打开绿谷-铁锈的星门，跃迁到铁锈星
- **任务说明**：
  从独石碑出发，往南走（或用坐标导航）。你会看到一个黑曜石星门框架，中央有一个紫色发光的方块（星门核心）。
  
  **使用方法**：手持【星门钥匙】，右键紫色核心 → 星门会打开（光效演出），你会被传送到铁锈星。
  
  欢迎来到第二个文明阶段！这里是工业时代的起点。钥匙消耗 1 个，如果需要回来，再制一个钥匙。
  
  **铁锈星的三条科技线**（接下来会指引）：
  1. 炼钢线 - 需要熔炉、坩埚、冶炼炉（Create mod）
  2. 机械线 - 齿轮、轴、铁板、管道（Create + Mekanism）
  3. 管道线 - 流体运输、气体压缩（Mekanism）
- **坐标**：绿谷星门 (0, ?, -100)；铁锈星着陆点（跃迁后提示）
- **奖励**：新维度已解锁、进度记录
- **下一步**：选择三条科技线之一开始探索

### ⑥-⑧ 【工业】三条科技线（并行）
- **目标**：完成铁锈星的三条科技线之一（炼钢 / 机械 / 管道）
- **任务说明**（每条线 1-2 个关键任务）
  
  **炼钢线**：
  - 采集铁矿和燧石
  - 在熔炉里制造铁锭
  - 进阶：用坩埚铸造复杂零件
  - 目标：获得【钢铁】
  
  **机械线**：
  - 用Create的旋转动力系统
  - 制造齿轮、轴、铁板
  - 需要来自工作台的【机械部件】
  - 目标：获得【精密齿轮组】
  
  **管道线**：
  - 构建 Mekanism 的压力管道网络
  - 提纯矿石、传输流体
  - 需要【液化铸铁】和【金属块】
  - 目标：能源储存达到 10,000,000 Joules
  
- **坐标**：铁锈星各地（任务会指示）
- **奖励**：钢板 ×8 / 精密齿轮 ×2 / 液化金属 ×1 bucket
- **下一步**：完成三线，集合生物燃料

### ⑨ 【农工交汇】生物燃料 → 跃迁硅火星
- **目标**：制造【生物燃料罐】，用于跃迁硅火星
- **任务说明**：
  回到绿谷，用上古之种在农场大规模种植（或找村庄商人）。
  
  在铁锈星的 Create 混合机（Mixer）里，用生物燃料和蒸馏液配方 → 生成【生物燃料罐】。
  
  这代表农业与工业的交汇：绿谷提供食物和燃料，铁锈提供精密加工。两个文明的合作。
  
  用钥匙回到绿谷，准备下一段旅程。
- **坐标**：铁锈星混合机位置；绿谷星门
- **奖励**：生物燃料罐 ×2
- **下一步**：前往硅火星，探索信息文明

### ⑩ 【信息】精密零件 + 跃迁硅火星
- **目标**：获得【精密零件】，打开硅火星星门
- **任务说明**：
  精密零件是信息时代的基础。合成它需要：
  - 铁板 ×1（从铁锭用锻压机制造）
  - 红石 ×2（采集或交易）
  - 金粉 ×1（用蚀刻机从金矿制造）
  
  配方会在 JEI 中显示。完成后，你手持【精密零件】。
  
  回到绿谷，用生物燃料罐右键星门核心（不同星门可能需要不同罐），进入硅火星。
  
  硅火星是高科技的殿堂：应用能源、计算机、量子存储等。但都建立在【精密零件】的基础上。
- **坐标**：铁锈星合成台；绿谷-硅火星星门
- **奖励**：精密零件 ×4、新维度解锁
- **下一步**：选择 AE2 或 RS 的存储路线

### ⑪ 【终局】跃迁引擎 + 灾厄 Boss
- **目标**：制造【跃迁引擎】，击败【灾厄 Boss】
- **任务说明**：
  到此为止，你已经掌握了四个文明阶段：农业、工业、信息、星际。
  
  跃迁引擎代表"终极成就"——能够自由穿梭五颗星球（包括隐藏的第五星——灾厄维度）。
  
  制造跃迁引擎需要：
  - 量子核心 ×1（AE2 或 RS 高端）
  - 跃迁晶体 ×8（从各星球收集的稀有矿物）
  - 终界水晶碎片 ×4（猎杀终界龙的奖励）
  
  同时，灾厄维度中隐藏着一只 Boss——【灾厄终主】。击败它是"真正的终局"，代表人类对一切的掌握。
  
  两个选择都是终点：
  - **和平线**：完成跃迁引擎，自由探险，收集所有 Boss 的战利品
  - **战斗线**：击败灾厄终主，获得《文明编年史·最后一章》
  
  无论哪条线，你的故事都会被永久记录。
- **坐标**：硅火星、苍穹星、灾厄维度（接近时指示）
- **奖励**：跃迁引擎 ×1 OR 灾厄之冠（Boss 掉落）、成就"文明的延续"
- **下一步**：自由探险，发现隐藏秘密，向社区分享你的"戴森球"
